# Portfolio Context & Summary

This project is a modern, high-performance web portfolio for **Prijesh Bhingradiya**, a Senior Software Developer.

## Overview
- It utilizes a 3D avatar character and animated 3D stack spheres to create an immersive, game-like portfolio UX.
- The project implements seamless smooth-scrolling through `gsap-trial/ScrollSmoother`.
- Developed with Antigravity and Gemini.

## File Structure
- `src/components/` - Houses isolated feature components (Landing, About, Career, Work, Contact).
- `src/context/` - Application global states, such as the `LoadingProvider`. 
- `src/assets/` - Local media including fonts, local images, and model binaries.
